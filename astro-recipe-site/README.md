# Astro Recipe Site

Recipe and cooking tutorial site built with Astro content collections, Recipe/HowTo schema.org structured data, AdSense, RSS feed, and sitemap.

## Features

- Astro content collections for recipes
- schema.org Recipe and HowTo structured data
- Responsive AdSense ad component
- RSS feed and sitemap generation
- SEO metadata with recipe-specific markup

## Getting Started

```bash
pnpm install
pnpm dev
```

## Scripts

- `pnpm dev` - Start development server
- `pnpm build` - Build for production
- `pnpm test` - Run tests
- `pnpm lint` - Lint source files

## Content

Add recipes as MDX files in `src/content/recipes/` with frontmatter including prep/cook times, ingredients, servings, and tags.
