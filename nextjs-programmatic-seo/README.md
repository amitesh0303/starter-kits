# Next.js Programmatic SEO

Data-generated landing pages built with Next.js App Router, PostgreSQL with Drizzle ORM, Inngest background jobs, and AdSense monetization.

## Features

- Next.js App Router with dynamic slug routes
- PostgreSQL database with Drizzle ORM
- Inngest background jobs for page generation
- SEO-optimized landing page templates
- Schema.org WebPage structured data
- AdSense ad slots

## Getting Started

```bash
cp .env.example .env.local
pnpm install
pnpm dev
```

## Scripts

- `pnpm dev` - Start development server
- `pnpm build` - Build for production
- `pnpm test` - Run tests
- `pnpm lint` - Lint source files
- `pnpm typecheck` - TypeScript type checking
