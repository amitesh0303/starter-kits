# Nuxt Magazine Site

Multi-author magazine and news site built with Nuxt, Nuxt Content for Markdown articles, AdSense monetization, image optimization, and Resend newsletter.

## Features

- Nuxt 3 with Nuxt Content module
- Markdown-based article authoring
- NewsArticle schema.org structured data
- AdSense ad components
- Image optimization
- Resend newsletter subscription
- Category-based article browsing

## Getting Started

```bash
cp .env.example .env
pnpm install
pnpm dev
```

## Scripts

- `pnpm dev` - Start development server
- `pnpm build` - Build for production
- `pnpm test` - Run tests
- `pnpm lint` - Lint source files

## Content

Add articles as Markdown files in `content/articles/` with frontmatter for title, author, category, and publication date.
