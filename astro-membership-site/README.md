# astro-membership-site

An Astro SSR starter for paid newsletter and premium content membership.

## Tech Stack

- **Framework:** Astro SSR
- **Auth:** Clerk
- **Data:** Turso/LibSQL
- **Billing:** Stripe
- **Email:** Resend

## Getting Started

1. Copy `.env.example` to `.env`
2. Run `pnpm install`
3. Run `pnpm dev`

## Scripts

- `pnpm dev` - Start development server
- `pnpm build` - Production build
- `pnpm test` - Run tests
- `pnpm lint` - Lint code
- `pnpm typecheck` - Type check
