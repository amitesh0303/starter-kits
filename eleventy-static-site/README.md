# Eleventy Static Site

Minimal niche or documentation site built with Eleventy 3.x, Markdown content, Nunjucks templates, AdSense, RSS feed, and sitemap.

## Features

- Eleventy 3.x static site generator
- Markdown posts with Nunjucks templates
- AdSense ad placeholders
- RSS feed generation
- Sitemap generation
- SEO structured data helpers

## Getting Started

```bash
pnpm install
pnpm dev
```

## Scripts

- `pnpm dev` - Start development server
- `pnpm build` - Build static site to `_site/`
- `pnpm test` - Run tests
- `pnpm serve` - Serve built site locally

## Content

Add posts as Markdown files in `src/posts/` with YAML frontmatter for title, description, date, and tags.
