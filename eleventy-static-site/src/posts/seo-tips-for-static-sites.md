## SEO Fundamentals

Static sites have a natural advantage for SEO thanks to their fast load times and simple HTML structure.

## Key Strategies

### Meta Tags

Always include descriptive title and meta description tags for every page.

### Structured Data

Add JSON-LD structured data to help search engines understand your content.

### Performance

- Optimize images
- Minimize CSS
- Use proper caching headers

## Sitemap and RSS

Generate a sitemap.xml and RSS feed to help search engines discover your content.
