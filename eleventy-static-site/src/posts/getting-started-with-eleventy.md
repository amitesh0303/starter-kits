## What is Eleventy?

Eleventy is a simple static site generator that transforms your content into fast, production-ready websites.

## Getting Started

1. Create your content in Markdown files
2. Design layouts with Nunjucks templates
3. Build and deploy

## Why Eleventy?

- Zero client-side JavaScript by default
- Works with multiple template languages
- Flexible data cascade
- Fast build times
