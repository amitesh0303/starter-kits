# remix-commerce-saas

A Remix starter for merchant storefront and D2C commerce.

## Tech Stack

- **Framework:** Remix
- **Auth:** Auth.js
- **Data:** Shopify API
- **Billing:** Stripe

## Getting Started

1. Copy `.env.example` to `.env`
2. Run `pnpm install`
3. Run `pnpm dev`

## Scripts

- `pnpm dev` - Start development server
- `pnpm build` - Production build
- `pnpm test` - Run tests
- `pnpm lint` - Lint code
- `pnpm typecheck` - Type check
