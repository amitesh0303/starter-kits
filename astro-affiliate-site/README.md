# Astro Affiliate Site

Affiliate product review site built with Astro, MDX content collections, schema.org structured data, affiliate link tracking, and AdSense monetization.

## Features

- MDX content collections for product reviews
- schema.org Review and Product structured data
- Affiliate link builder with tracking parameters
- Responsive AdSense ad component
- RSS feed and sitemap generation
- SEO metadata utilities

## Getting Started

```bash
pnpm install
pnpm dev
```

## Scripts

- `pnpm dev` - Start development server
- `pnpm build` - Build for production
- `pnpm test` - Run tests
- `pnpm lint` - Lint source files
- `pnpm check` - TypeScript checking

## Content

Add reviews as MDX files in `src/content/reviews/` with frontmatter including product details, ratings, pros/cons, and affiliate URLs.
