## What is Hugo?

Hugo is a fast and modern static site generator written in Go. It is optimized for speed and designed for flexibility.

## Getting Started

1. Install Hugo
2. Create a new site: `hugo new site mysite`
3. Add content as Markdown files
4. Build with `hugo`

## Why Hugo?

- Extremely fast build times (sub-second for most sites)
- Built-in templates and shortcodes
- Multilingual support
- No dependencies required
