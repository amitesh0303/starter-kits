## What is Pagefind?

Pagefind is a fully static search library that indexes your site at build time and provides lightning-fast search without any server infrastructure.

## Integration Steps

1. Build your Hugo site
2. Run Pagefind to index the output
3. Include the Pagefind UI in your templates

## Benefits

- No server required
- Works on any static hosting
- Tiny bundle size
- Supports multiple languages
