# sveltekit-ai-saas

A SvelteKit starter for usage-metered AI and data tooling SaaS.

## Tech Stack

- **Framework:** SvelteKit
- **Auth:** Supabase Auth
- **Data:** Supabase Postgres
- **Billing:** Stripe Billing Meters
- **AI:** AI provider (OpenAI-compatible)

## Getting Started

1. Copy `.env.example` to `.env`
2. Run `pnpm install`
3. Run `pnpm dev`

## Scripts

- `pnpm dev` - Start development server
- `pnpm build` - Production build
- `pnpm test` - Run tests
- `pnpm lint` - Lint code
- `pnpm typecheck` - Type check
