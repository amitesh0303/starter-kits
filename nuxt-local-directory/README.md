# Nuxt Local Directory

Local business and city directory built with Nuxt, Supabase Postgres, MapLibre/OpenStreetMap mapping, Meilisearch full-text search, and AdSense monetization.

## Features

- Nuxt 3 with server-side rendering
- Supabase Postgres database
- MapLibre GL JS with OpenStreetMap tiles
- Meilisearch search integration
- Schema.org LocalBusiness structured data
- AdSense with sponsored listings
- Category browsing and map views

## Getting Started

```bash
cp .env.example .env
pnpm install
pnpm dev
```

## Scripts

- `pnpm dev` - Start development server
- `pnpm build` - Build for production
- `pnpm test` - Run tests
- `pnpm lint` - Lint source files
