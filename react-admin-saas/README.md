# react-admin-saas

A React + Vite starter for CRM, ERP, and internal admin panels.

## Tech Stack

- **Framework:** React + Vite
- **Auth:** Auth0
- **Data:** Supabase Postgres
- **Billing:** Stripe
- **UI:** shadcn/ui + TanStack Query

## Getting Started

1. Copy `.env.example` to `.env`
2. Run `pnpm install`
3. Run `pnpm dev`

## Scripts

- `pnpm dev` - Start development server
- `pnpm build` - Production build
- `pnpm test` - Run tests
- `pnpm lint` - Lint code
- `pnpm typecheck` - Type check
