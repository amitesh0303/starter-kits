# react-collaboration-saas

A React + Vite starter for collaborative documents and boards with real-time features.

## Tech Stack

- **Framework:** React + Vite
- **Auth:** Clerk
- **Data:** Convex
- **Realtime:** Liveblocks
- **Billing:** Stripe

## Getting Started

1. Copy `.env.example` to `.env`
2. Run `pnpm install`
3. Run `pnpm dev`

## Scripts

- `pnpm dev` - Start development server
- `pnpm build` - Production build
- `pnpm test` - Run tests
- `pnpm lint` - Lint code
- `pnpm typecheck` - Type check
