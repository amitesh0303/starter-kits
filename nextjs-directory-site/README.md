# Next.js Directory Site

Business and tools directory built with Next.js App Router, Supabase Postgres with Drizzle ORM, Meilisearch for full-text search, and AdSense monetization.

## Features

- Next.js App Router with server components
- Supabase Postgres database with Drizzle ORM
- Meilisearch full-text search integration
- LocalBusiness schema.org structured data
- Responsive AdSense ad slots
- SEO-optimized category and listing pages

## Getting Started

```bash
cp .env.example .env.local
pnpm install
pnpm dev
```

## Scripts

- `pnpm dev` - Start development server
- `pnpm build` - Build for production
- `pnpm test` - Run tests
- `pnpm lint` - Lint source files
- `pnpm typecheck` - TypeScript type checking
