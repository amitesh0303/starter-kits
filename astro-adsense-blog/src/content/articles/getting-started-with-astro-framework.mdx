# Getting Started With the Astro Framework

Astro is a modern static site generator that delivers lightning-fast performance by shipping zero JavaScript to the client by default.

## Why Choose Astro?

Astro is designed for content-rich websites. It supports multiple UI frameworks and delivers excellent Core Web Vitals scores out of the box.

### Key Features

- **Zero JavaScript by default** - Only ship JS when you need interactivity
- **Component Islands** - Hydrate interactive components independently
- **Content Collections** - Type-safe markdown and MDX content management
- **Built-in optimizations** - Automatic image optimization and asset bundling

## Getting Started

Install Astro using your preferred package manager:

```bash
pnpm create astro@latest
```

This creates a new project with everything you need to start building.

## Next Steps

Explore the official documentation to learn about layouts, pages, and components. Astro makes it easy to build fast, accessible websites.
