# nuxt-community-saas

A Nuxt starter for membership community and forum SaaS.

## Tech Stack

- **Framework:** Nuxt
- **Auth:** Better Auth
- **Data:** PostgreSQL + Drizzle
- **Billing:** Paddle

## Getting Started

1. Copy `.env.example` to `.env`
2. Run `pnpm install`
3. Run `pnpm dev`

## Scripts

- `pnpm dev` - Start development server
- `pnpm build` - Production build
- `pnpm test` - Run tests
- `pnpm lint` - Lint code
- `pnpm typecheck` - Type check
