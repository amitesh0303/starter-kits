# Next.js Job Board

Job board and recruitment directory built with Next.js App Router, Clerk authentication, PostgreSQL with Drizzle ORM, Stripe paid listings, and AdSense.

## Features

- Next.js App Router with server components
- Clerk authentication for employers
- PostgreSQL database with Drizzle ORM
- Stripe integration for paid job listings
- Schema.org JobPosting structured data
- AdSense monetization
- Category-based job browsing

## Getting Started

```bash
cp .env.example .env.local
pnpm install
pnpm dev
```

## Scripts

- `pnpm dev` - Start development server
- `pnpm build` - Build for production
- `pnpm test` - Run tests
- `pnpm lint` - Lint source files
- `pnpm typecheck` - TypeScript type checking
