## High-level view

The shared `fakeTokenStore` singleton exported from `secure-store.ts` eliminates the isolated-Map problem. All three auth-touching files import the same instance, so sign-in tokens flow correctly to the auth guard and deep-link handler.

The `createSQLiteQueuePersistence` factory bridges `QueuePersistence.onEnqueue` to `repo.insertAction` and `onTransition` to `repo.updateActionState`, with try/catch around each call so the in-memory queue remains authoritative when SQLite fails.

Crash recovery is exercised by 7 new test cases: orphaned syncing actions transition back to pending, persistence callbacks fire for each recovery, and recovered actions are re-processable. The bridge itself has a 5-test suite validating mapping and error resilience.
