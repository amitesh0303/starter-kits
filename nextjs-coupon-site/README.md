# Next.js Coupon Site

Deals and coupons site built with Next.js App Router, PostgreSQL with Drizzle ORM, Meilisearch full-text search, Inngest background jobs, and AdSense with affiliate tracking.

## Features

- Next.js App Router with server components
- PostgreSQL database with Drizzle ORM
- Meilisearch for coupon search
- Inngest for background coupon verification
- Affiliate tracking for click-through revenue
- AdSense ad slots
- Store and category pages

## Getting Started

```bash
cp .env.example .env.local
pnpm install
pnpm dev
```

## Scripts

- `pnpm dev` - Start development server
- `pnpm build` - Build for production
- `pnpm test` - Run tests
- `pnpm lint` - Lint source files
- `pnpm typecheck` - TypeScript type checking
